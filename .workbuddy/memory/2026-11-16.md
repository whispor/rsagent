# 2026-11-16

## 持续优化 rsagent（两批共 8 项）

范围经用户确认：「两批都做」。改动覆盖 3 个 crate，新增 3 个文件。

**第一批（低风险高收益）**
1. **工具/噪声目录**：`tools.rs` 新增 `SKIPPED_DIRS`（`.git`/`target`/`node_modules`/`.venv`/`venv`/`__pycache__`）与 `is_skipped_dir`；`search` 递归时不再下降进这些目录（用户显式指向的根仍会搜索）。
2. **新增 `glob` 工具**：支持 `*`（段内）、`?`、`**`（跨段）；无 `/` 的模式按文件名匹配。为保持零新依赖，自研匹配器 `crates/rsagent-agent/src/glob.rs`（段递归 + 段内线性通配回溯），5 个单测。
3. **会话恢复**：`Agent::set_system_prompt`；`main.rs` 恢复 session 时，若未传 `--system` 则用保存的 system_prompt 覆盖。
4. **CI**：新增 `.github/workflows/ci.yml`（checkout → rust-toolchain stable+rustfmt+clippy → rust-cache → fmt --check → clippy -D warnings → test），push main / PR 触发。
5. **Cargo 元数据**：`workspace.package` 增 `repository`，三个 crate 继承。
6. **CLI 集成测试**：`crates/rsagent/tests/cli.rs`，用 `env!("CARGO_BIN_EXE_rsagent")` 直接跑二进制，覆盖 `--faux --print` 端到端与 `--version`。

**第二批**
7. **上下文预算裁剪**：`Agent` 每轮请求前按 turn 边界裁剪 transcript（预算 = `context_window * 3/4`，token ≈ 字符/4）；**保留首轮与最近轮**，从中间较早轮次开始丢，整轮丢弃以保证 tool_call 与 result 不被拆散。新增 `AgentEvent::ContextCompacted{dropped_messages}`，Renderer 打印一行提示。此机制同时把 transcript 规模限制住，从而**间接收敛了原先每轮 `build_context` 克隆整份 transcript 的 O(n²) 成本**——因此未做 Arc 化等侵入式改造（符合「简洁优先」）。
8. **性能微调**：`run_turns` 重排，先取出 `stop_reason`/`error_message`/`tool_calls` 再把 assistant move 进 `Message::Assistant`，省掉一次整消息深拷贝。

**附带发现并修复的安全问题**：clap 默认会在 `--help` 里打印 env **值**，导致 `rsagent --help` 直接输出 `RSAGENT_API_KEY=...`。已在三个 env 参数上设置 `hide_env_values = true`（注意：clap 4 无命令级 `hide_env_values`，只能逐参数设）。

**验收**：`cargo fmt --all --check` 干净；`cargo clippy --workspace --all-targets -- -D warnings` exit 0；`cargo test --workspace` **27 项全过**（CLI 2 + glob 5 + agent_loop 14 + ai 3 + faux 3）；冒烟 `--faux --print`、`--version`(rsagent 0.1.0)、`--help` 均正常。

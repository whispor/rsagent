### C1 · 只读命令不启动进程（提交 `d632905` + 状态 `c995959`）

**问题**：`rsagent.toml` 声明的 `local` / `mcp-stdio` / `mcp-http` 来源在**装配期、任何审批
之前**就被启动——`git clone && rsagent --list-tools` 会执行仓库声明的任意命令。

**实现**（`crates/rsagent/src/main.rs`、`tools.rs`、`crates/rsagent-agent/src/source.rs`）：
- `SourceHealth` 新增 `NotChecked` 变体（只描述、未启动，**刻意不是** `Unhealthy`）。
- 新增二值 enum `SourceMode::{Assemble, DeclaredOnly}`（**不是** `spawn: bool`——项目
  `max-fn-params-bools = 0` 禁布尔参数）；`--list-tools` 走 `DeclaredOnly`。
- `DeclaredSource` 只报 kind/id，`tools()` 为空、`health()` = `NotChecked`。
- `build_source` 在 `DeclaredOnly` 下**先校验必填字段**（缺 `command`/`url`、未知 kind 仍
  退非零）再返回声明态；`builtin`/`skill`/`web` 三种**照常装配**（构造不触达外部）。
- `report()` 对 `NotChecked` 隐藏工具数、**不计为问题**（否则 D4 退出码会把只读命令变恒红）。
- `main()` 的 `too_many_lines` 超限：抽出 `fail(palette, error) -> !` 消除重复的
  `eprintln! + exit(2)`，并 `mode` → `source_mode` 重命名。

**测试（+2）**：`read_only_commands_never_start_a_local_source`（脚本写 `touched.txt`，断言
未出现）、`read_only_mode_still_assembles_the_sources_that_start_nothing`（builtin+skill+web
仍列出工具）。重命名两个 `..._but_not_started`；按新语义改写 `an_unreachable_mcp_http_source_...`
与 `tools_doctor_fails_on_an_unloadable_source`（改用缺 `command` 的配置错误）。

**A/B**：把 `--list-tools` 的 `SourceMode` 临时改回 `Assemble` → 新测试 FAILED
（`rsagent --list-tools` must not run the local source's command）。

**文档**：README（信任边界 / Managing tool sources）、EXTENSIBILITY.md §3.6、`doctor` 帮助文本、

### C2 · 蒸馏笔记每 5 轮最多一条（提交 `9ca215a` + 状态 `093562a`）

**问题**：每次裁剪都追加 `[compacted]` 笔记，该笔记下一轮进入 system prompt、撑大预算——
「裁剪 → 写笔记 → prompt 变大 → 再裁剪」软回路。

**实现**（`crates/rsagent-agent/src/agent.rs`）：常量 `DISTILL_QUIET_TURNS = 5`；字段
`turn` / `last_distill_turn`；`run_turns` 每轮 `turn.saturating_add(1)`；`distill` 改
`&mut self`，距上次写笔记 <= 5 轮直接返回；**仅实际写入后**才置 `last_distill_turn`
（空 digest 不启动静默窗）。**未改** `distill_messages` 内容/格式，**未动** `Memory` 存储约定。

**测试（+1）**：`compaction_notes_are_rate_limited_to_one_per_few_turns`（窗口 40、5 条 300 字
种子、连续 6 次 prompt 各触发一次裁剪 → `compactions >= 6` 且 `[compacted]` 笔记恰 1 条）。
**A/B**：频率门前加 `if false &&` → 测试 FAILED（saw 6）。

**文档**：README（Memory 节 + `--memory` 说明）、ARCHITECTURE.md §6、EXTENSIBILITY.md §3.7、

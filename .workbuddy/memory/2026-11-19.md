### 第一段 · H1–H7（静默错误与数据丢失）

分 4 个提交落地：

- **`3b22d5f`（rsagent-ai，H1–H3）**
  - **H1**：Anthropic 流解析器加 `failed: bool`；见到 `error` 事件即置位，`finish()` 见 `failed` 直接返回空，**不再在错误后补发 `Done`**（消费方「最后一个终止事件获胜」会把失败读成空成功、退 0）。
  - **H2**：`assistant_blocks` 先回放 `thinking` 块（含 signature），再排文本与 tool_use，`--thinking` + 工具调用不再在第二轮被 400 拒绝。
  - **H3**：SSE `next_line` 由 `&mut String` 改 `&mut Vec<u8>`（原始字节），只在完整行处解码——跨 chunk 被切断的多字节字符（中文/emoji）不再变成 U+FFFD。
- **`e939f87`（rsagent-agent，H4–H5）**
  - **H4**：`sources/subprocess.rs` 的 `run()` 把「写入 + 等待退出 + 排空管道」收进**同一个 `tokio::time::timeout`**；`kill_on_drop(true)`；共享字节汇聚（`Arc<StdMutex<Vec<u8>>>`）；新增 `DRAIN_GRACE`（1s）+ `drain_within`（超时即 `abort`）；`platform.rs` 加 `kill_tree`（Windows `taskkill /F /T`）。后台守护进程攥着继承管道不再永久挂死。
  - **H5**：`mcp_stdio.rs` 抽 `trim_front_to_limit`，用 `while !text.is_char_boundary(cut) { cut += 1 }` 把截断点推进到字符边界，stderr 尾部裁剪不再在 UTF-8 边界 panic。
- **`c8f6351`（rsagent，H6–H7）**
  - **H6**：`session.rs` 大改——新增 `IncompatibleVersion` 错误；`load()` 遇更新版本即 `read_only = true`，`save()` 直接跳过（**新版本文件永不被覆盖**）；`save_jsonl` 用 `can_append`（`last_written` 指纹）判定能否追加，压缩过的记录改重写而非追加；`load_jsonl` 返回 `JsonlLoad { context, written, needs_rewrite, dropped_tail }`，无头文件的空 JSONL 会被补头重写。
  - **H7**：`main.rs` 新增 `load_dotenv()`——记录 `.env` 前的既有环境变量，跑 `dotenvy::dotenv()` 后**移除**由 `.env` 新引入的受保护变量（`RSAGENT_BASE_URL` / `RSAGENT_USER_CONFIG`）并告警；克隆来的仓库无法再把 API key 导向攻击者端点。`config.rs` 加 `# Trust boundary` 模块文档。
- **`c8d5249`（文档）**：README / STABILITY / CHANGELOG / `.env.example` 同步（base URL 移出 `.env`、信任边界说明、会话并发措辞修正、H1–H7 记入 Fixed）。

## 依据 BeautifulRust 优化 RsAgent 工作区

**背景**：BeautifulRust (morganlinton/BeautifulRust) 是 Agent Skills 仓库（rust-best-practices / rust-review / rust-port + clippy 配置），非可引入库。优化方式 = 采纳其 `lints.toml` + `clippy.toml` 规则并修正代码。

**修复的阻断问题**（原工作区无法编译）：
- `crates/rsagent-ai/src/lib.rs` 未从 crate 根导出 `FauxProvider` / `FauxResponse` / `FauxBlock` / `OpenAiProvider` → 已补 `pub use providers::{...}`。
- `clap` 缺 `env` feature（`#[arg(env=...)]` 报错）→ workspace 依赖加 `"env"`。
- `main.rs` 未使用的 `Message` 导入 → 移除。

**采纳的配置**：
- 根 `Cargo.toml` 新增 `[workspace.lints]`（照搬 BeautifulRust lints.toml：pedantic + unwrap_used + missing_docs + as_conversions + print_stdout 等）。
- 新增根 `clippy.toml`：`max-fn-params-bools = 0`、测试内允许 unwrap/print、`doc-valid-idents` 增补 OpenAI 等专有名词。
- 三个 crate 加 `[lints] workspace = true`；bin `rsagent` 用 `#![expect(clippy::print_stdout, reason=...)]` 例外。

**关键代码改动**：
- `now_millis`：`as_millis() as i64` → `i64::try_from(...).unwrap_or(i64::MAX)`（消除有损转换）。
- `Model::with_reasoning(bool)` → 拆为 `with_reasoning()` / `without_reasoning()`（消除 bool 参数）；补 `#[must_use]`。
- `faux.rs`：`Mutex::lock().unwrap()` → `unwrap_or_else(PoisonError::into_inner)`（同时消除 unwrap_used 与 missing_panics_doc）。
- `openai.rs`：消除冗余 clone、`single_match_else`→`if let`、`as usize`→`usize::try_from`、合并 match 分支/or-pattern、`needless_continue`。
- `agent.rs`：抽取 `run_tool_calls` 辅助函数（消 `too_many_lines`）；`emit` 改收 `&AgentEvent`；为 `Agent` / `Models` / 各 Provider/Tool 补 `Debug`；`content`→`data` 消 `similar_names`。
- 全量补齐公共项 rustdoc（struct/enum/field/variant/method）、`# Errors` 段落。

**结果**：`cargo clippy --workspace --all-targets -- -D warnings` 通过（0 告警），`cargo test` 通过，`cargo fmt --check` 干净，CLI `--faux --print` 冒烟通过。

**约定**：本项目 lint 基线来自 BeautifulRust；新增代码需满足 `cargo clippy -- -D warnings`，抑制须用 `#[expect(..., reason=...)]`。

## 续：按 BeautifulRust rust-review 复审并修正

取回 `rust-best-practices` / `rust-review` 全文后复审，修复：

- **锁中毒**（纠正上一轮引入的违规）：`faux.rs` 由 `PoisonError::into_inner` 恢复改为 `.lock().expect("...")`，并补 `# Panics` 文档。规则：§5「Lock poisoning is fatal… Don't recover with `into_inner`」。
- **库公共 API 暴露 `anyhow::Error`**：新增 `crates/rsagent-agent/src/error.rs`，`AgentError`（thiserror）含 `NoResult` / `MaxTurnsExceeded{max_turns}`，`#[non_exhaustive]`；`Agent::prompt`/`run_loop` 改为返回 `Result<(), AgentError>`。规则：§5「Never expose anyhow::Error in a library's public API」。

- **消除可达 panic**：`FauxProvider` 由 `models: Vec<Model>` 改为单字段 `model: Model`，`model()`/`models()` 不再索引 `models[0]`。
- **补测试**（§11）：新增 `crates/rsagent-ai/tests/faux_provider.rs`（3 例）、`crates/rsagent-agent/tests/agent_loop.rs`（5 例），覆盖文本轮次、工具执行、未知工具、模型错误、max_turns。

## 续：落实上一轮 Consider 项（Arc 出公共签名 + non_exhaustive）

用户确认后推进两项。

- **`Arc` 移出公共签名**：
  - `rsagent-ai`：`Models` 改 `#[derive(Clone, Default)]` + 内部 `providers: Arc<HashMap<String, Arc<dyn Provider>>>`（手写 `Debug`）；`register` 用 `Arc::make_mut`；**删除 `register_arc`**；`get_provider` → `Option<&dyn Provider>`、`providers()` → `Vec<&dyn Provider>`（不再吐 `Arc`）。
  - `FauxProvider` 改 `#[derive(Debug, Clone)]` + `inner: Arc<Inner>`（`model` / `responses: Mutex<VecDeque<..>>` / `chunk_delay_nanos: AtomicU64` / `call_count: Mutex<usize>`）→ 廉价 Clone，调用方可 register 一个 clone、另留一个 clone 来 script。`id()` 返回 `&'static str`。
  - `Agent`：`models: Models`（按值）、`tools: Vec<Box<dyn Tool>>`；`new(models: Models, ...)`、`with_tools(Vec<Box<dyn Tool>>)`。
  - `builtin_tools()` → `Vec<Box<dyn Tool>>`。
  - `main.rs` / 两个测试：去掉 `Arc::new(models)`、`Arc::clone`、`register_arc`，改用 `models.register(faux.clone())` 与按值传 `Models`。
  - 约定：库公共 API 不出现 `Arc`；共享状态用「内部 `Arc<Inner>` + 廉价 `Clone`」模式。
- **`#[non_exhaustive]`**：加于 `StreamEvent`、`ErrorReason`（event.rs）、`ContentBlock`、`Message`（message.rs）、`StopReason`（types.rs）、`AgentEvent`（agent 层）。下游所有 match 已有 `_` 通配分支，无需补。

**结果**：`cargo fmt` 干净；`cargo clippy --workspace --all-targets -- -D warnings` 0 告警；`cargo test --workspace` 9 例全过；`cargo doc --no-deps` 无告警；CLI `--faux --print` 冒烟通过。

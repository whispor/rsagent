## 项目重评估与「A→C→B」三批推进

**重评估结论**（实用性/易用性/简洁度）：分层干净、文档与工程化超出「最小实现」预期。真正值得动的是实用性缺口（读类工具无路径围栏、`read_file` 无行号、`thinking` 未接线）与一处简洁度冗余（`search`/`glob` 重复遍历）。方案分三批：**A 速赢 → C 整洁 → B 稳健与安全**，用户选择「全部按优先级推进」。

**关键发现**：`StreamOptions.thinking` **声明但从未被 provider 读取**（所有 `thinking` 引用都在解析响应侧）。故 B3「`--thinking` 参数」若只加 CLI 就是空开关——必须同时改两个 provider 的 `build_request_body`（纯函数、可单测）。B3 成本由「低」升为「中」。

### A 批（已实现，速赢）

1. **REPL 行编辑与历史**：引入 `rustyline`（`default-features = false`，仅核心编辑 + 内存历史）。新增 `src/input.rs`：**单线程独占 stdin**，REPL 与审批共用（避免两个 reader 抢字节）。stdin 为终端时用 rustyline；为管道时**回退到朴素 `read_line`**，故管道输入（测试、脚本）行为不变。异步接口用 `mpsc`(请求) + `oneshot`(回复)。`Recall::{Remember,Forget}` 区分是否入历史（REPL 入、审批不入）。
2. **`read_file` 行号 + `offset`/`limit`**：每行前缀 `{n:>width}\t`，右对齐；越界/空文件给明确提示；范围读取加脚注 `… (showing lines a-b of N)`。
3. **会话版本号 + `--continue`**：`SessionFile { version, context }` 信封，`SESSION_VERSION = 1`。加载时先解析为 `Value`，有 `version` 键按新格式（`>1` 则 `bail!` 拒绝而非误读），否则按旧的裸 `Context` 兼容。`--continue` = `--session .rsagent-session.json`。
4. **`NO_COLOR` / `--no-color`**：新增 `src/render.rs` 的 `Palette`（`ColorChoice::{Auto,Never}`），非 TTY 自动关色；`Palette::paint` 统一上色。抽出 `render_thinking_delta`/`render_text_delta`/`render_stream_error`/`print_approval_prompt`，把 `Renderer::render` 压到 100 行以内。

**踩到的项目约定（重要）**：`clippy.toml` 设 `max-fn-params-bools = 0`——**任何 bool 函数参数都会告警**，必须改用枚举（`Recall`、`ColorChoice`）。`struct_excessive_bools`（阈值 3）对 `Cli` 触发，用 `#[expect(..., reason = "...")]` 显式豁免（项目用 `expect` 而非 `allow`，且必须带 reason）。`doc_markdown` 要求 `NO_COLOR` 加反引号。

**验收（A 批）**：fmt 干净；`clippy --all-targets -D warnings` exit 0；`cargo test --workspace --locked` **45 项全过**（CLI 12 + 单元 9 + agent_loop 18 + ai 3 + faux 3）。新增测试：`read_file` 行号/范围/全量、会话版本恢复/旧格式兼容/新版本拒绝/`--continue` 两轮、`--no-color` 无转义码。

### C 批（已实现，整洁）

- **C1 合并 `search`/`glob` 目录遍历**：新增 `opt_str`/`opt_count` 参数助手 + `read_children(dir) -> Children{dirs,files}`（集中「跳过 build/vendor 子目录」策略与 dir/file 分类）。`search`/`glob`/`list_dir` 改用之，消除两处重复的显式栈遍历。提交 `b315be8`。
- **C2 拆分 `main.rs` 渲染逻辑**：把 `Renderer` 及其展示助手（`describe_action`/`tool_display_name`/`arg_str`/`quote`/`compact`/`truncate`）整体迁入 `render.rs`。`main.rs` 由 **809 行降至 531 行**，`render.rs` 成为内聚的「输出层」模块（351 行）。`Renderer::palette` 与 `flush_line` 改 `pub(crate)`。提交 `165e8a6`。

### B 批（已实现，稳健与安全）

- **B1 读类工具路径围栏**：`tool.rs` 新增 `PathFence::{WorkingDirectory,Unrestricted}` 与 `ToolContext::resolve_within`（**先 `tokio::fs::canonicalize` 再 `starts_with` 边界判断**，故 `..` 与符号链接逃逸都会被拒，且能明确报错）。`Agent` 新增 `fence` 字段 + `with_path_fence`；`execute_one` 据 `fence` 给 `ToolContext` 加围栏。`read_file`/`list_dir`/`search`/`glob` 改用 `resolve_within`。CLI 新增 `--allow-outside-cwd`。审批提示（`write_file`/`edit_file`）对越界路径加 `⚠ 该路径在工作目录之外` 警告（`looks_outside_cwd` 纯词法判断，仅提示用）。提交 `b083a10`。
  - **踩坑**：默认围栏使 5 个既有测试（用 temp 绝对路径读文件）失败 → 新增 `harness_in(cwd, ...)`，让这些测试把 cwd 设为各自 temp 目录。
- **B2 工具白名单开关**：`tools.rs` 新增纯函数 `select_builtin_tools(only, exclude)`（`only` 白名单；`exclude` 在其后强制移除，故 `--no-bash` 优先于 `--tools`；返回未知名列表供告警）。CLI 新增 `--tools <LIST>`（`value_delimiter=','`）与 `--no-bash`。`main.rs` 抽出 `choose_tools`。5 个单测 + 1 个 CLI 告警测试。提交 `1c2fbab`。
- **B3 `--thinking`**：把此前「声明未接线」的 `StreamOptions.thinking` 真正接入两个 provider 的 `build_request_body`。OpenAI → `reasoning_effort`（`xhigh`/`max` 饱和为 `high`）；Anthropic → `thinking:{type:enabled,budget_tokens}`（级别→预算，**上限 `min(budget, max_tokens-1)`，不足 1024 则丢弃**；thinking 开启时 Anthropic 禁止自定义 temperature，故丢弃 `--temperature`）。CLI `--thinking <level>`（`value_parser = parse_thinking`，默认 `off`）。2 个 provider 单测 + 1 个非法级别 CLI 测试。提交 `a97b54f`。

**验收（C+B 批）**：每批均 fmt 干净、`clippy --workspace --all-targets --locked -D warnings` exit 0、`cargo test --workspace --locked` 全过；测试数 **45 → 47 → 53 → 56**。五批提交（`b315be8`/`165e8a6`/`b083a10`/`1c2fbab`/`a97b54f`）全部推送 `origin/main`，GitHub Actions CI 均 `conclusion: success`。
